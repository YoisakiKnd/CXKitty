# 学习通工具箱（cxkitty-tauri）

单账号学习通桌面工具：登录后共用一个会话，提供 **作业列表 / 考试列表 / 刷课（视频+文档任务点自动完成）**。

技术栈：**Rust + Svelte + Tauri 2**。协议：**GPL-3.0**。

> 超星相关开源项目（如 CXKitty、query-chaoxing-worklist 等）仅作 **接口 URL / 参数 / 加密方式** 的参考，本仓库为独立实现，并非合并或照搬整仓。

## 功能

1. **登录**：密码登录（AES-CBC，`u2oh6Vu^HWe4_AES`）→ 全局 Cookie 会话  
2. **作业**：按课程拉取作业名、状态、截止时间、成绩（仅查询）  
3. **考试**：按课程拉取考试列表与状态（仅查询，不作答）  
4. **刷课（视频 + 文档）**  
   - 按课程遍历未完成章节  
   - **视频**：拉取 dtoken / duration，按间隔上报播放进度（MD5 `enc`，403 自动重试一次）  
   - **文档**：`ananas/job/document` 阅读上报  
   - **测验 / 作业 / 考试类任务点**：自动标记「已跳过-非刷课类型」，不调用任何作答接口  
   - 进度通过 Tauri 事件 `brush-progress` 推送到前端日志与任务点状态表  

**明确不做**：代答 / 搜题 / 题库、测验自动作答、考试自动提交或替考、多账号体系、人脸、通知中心。

## 刷课用法

1. 登录 → 选择课程 → 打开 **刷课** 页  
2. （可选）勾选「仅未完成章节」，调整视频倍速（建议 1.0～2.0）  
3. 点 **开始刷课**；日志与每条任务点状态实时更新  
4. 需要中断时点 **停止**（当前视频会在下一秒检测后退出）  

也可先「拉取章节 / 任务点」仅浏览，再开始刷课。

## 开发运行

环境：Node.js 18+、Rust（stable）、系统 Tauri 依赖（Linux 需 WebKitGTK 等）。

```bash
cd /workspace/cxkitty-tauri
npm install
npm run tauri dev
```

仅检查后端：

```bash
cd src-tauri && cargo check
```

仅构建前端：

```bash
npm run build
```

### 关于 `tauri build`

无图形库 / 无完整系统依赖的 CI 或无头环境中，`tauri build` 可能失败，属预期。本地有桌面依赖时再打包即可。
